# Great White Stremio

Experimental Great White Android client based on the community Stremio Native Android project.

- Install ID: `tv.gws.stremio`
- Designed to coexist with standard Stremio package IDs.
- One codebase targets Android phones/tablets and Android TV/Google TV.
- TV launcher capability is enabled in the GWS build.
- Current CI artifact is a test build; production signing/release comes after device verification.
- No third-party piracy-oriented add-ons are bundled or auto-installed.

Upstream: https://github.com/stremio-native/stremio-android
